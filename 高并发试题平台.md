## 1\. Recommended Tech Stack

| -------------------- | ------------------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| **Frontend**         | React 18 + Vite + Tailwind CSS                   | Fast dev server, tree-shaking, utility-first styling for rapid UI development                             |
| **State Management** | Zustand                                          | Lightweight, no boilerplate, excellent for auth/session state                                             |
| **Routing**          | React Router v6                                  | Declarative routing, nested routes for admin panel                                                        |

| **Backend**          | Node.js + Express.js                             | Mature ecosystem, massive community, proven at scale                                                      |
| **Database**         | PostgreSQL 15                                    | ACID compliance, complex relational queries (joins for analytics), row-level locking for concurrent exams |
| **ORM**              | Prisma                                           | Type-safe, migration management, excellent query optimization                                             |
| **Caching**          | Redis (ioredis)                                  | Session storage, leaderboard caching, rate limiting, question bank caching                                |
| **Authentication**   | JWT (Access + Refresh tokens) + bcrypt           | Stateless auth, scalable across multiple server instances                                                 |
| **File Upload**      | Multer + csv-parser                              | Stream-based CSV parsing for memory-efficient bulk uploads                                                |
| **Validation**       | Zod                                              | Runtime type safety, declarative schemas for API contracts                                                |
| **Real-time**        | Socket.io (optional v2)                          | Live leaderboards, exam countdown sync                                                                    |
| **Containerization** | Docker + Docker Compose                          | Consistent environments, easy horizontal scaling                                                          |
| **Reverse Proxy**    | Nginx                                            | Load balancing, SSL termination, static asset serving                                                     |
| **Monitoring**       | Winston (logging) + Prometheus/Grafana (metrics) | Production observability                                                                                  |

| Import | Source | Purpose                         |

## Logic Steps

- **Load .env** - call dotenv.config() before any other config reads.
- **Define Zod Schema** - map every env var to a Zod type with constraints:
  - PORT: coerce to number, default 5000
  - NODE_ENV: enum development | production | test, default development
  - DATABASE_URL: non-empty string (PostgreSQL connection string)
  - REDIS_URL: non-empty string
  - JWT_ACCESS_SECRET: min length 32
  - JWT_REFRESH_SECRET: min length 32
  - JWT_ACCESS_EXPIRY: string, default 15m
  - JWT_REFRESH_EXPIRY: string, default 7d
  - BCRYPT_SALT_ROUNDS: coerce to number, default 12
  - FRONTEND_URL: URL string, default <http://localhost:5173>
  - RATE_LIMIT_WINDOW_MS: coerce to number, default 900000 (15 min)
  - RATE_LIMIT_MAX_REQUESTS: coerce to number, default 100
  - LOG_LEVEL: enum, default info
- **Parse & Validate** - schema.parse(process.env) throws on invalid/missing values.
- **Export** - freeze the parsed object so it cannot be mutated at runtime.

REDIS_URL: z  
.string()

.default('redis://localhost:6379'),  
<br/>// JWT  
JWT_ACCESS_SECRET: z  
.string()  
.min(32, 'JWT_ACCESS_SECRET must be at least 32 characters long'),  
<br/>JWT_REFRESH_SECRET: z  
.string()  
.min(32, 'JWT_REFRESH_SECRET must be at least 32 characters long'),

## Logic Steps

- **Import & Setup** - Load Winston, DailyRotateFile, and the validated env config.
- **Define Log Format** - Combine:
  - timestamp (ISO 8601)
  - errors({ stack: true }) (capture stack traces)
  - splat() (string interpolation)
  - json() (structured output for log aggregation)
- **Build Transports Array** - Conditionally:
  - **Always**: Console transport with colorization for readability.
  - **Production only**: Two DailyRotateFile transports:
    - error-%DATE%.log - level: 'error', max 14 days, max 20MB.
    - combined-%DATE%.log - all levels, max 14 days, max 20MB.
- **Create Logger** - winston.createLogger({ level, format, transports, exceptionHandlers, rejectionHandlers }).
- **Graceful Exit** - On SIGINT, close transports before process exit.

## Complete Code: backend/config/logger.js

const winston = require('winston');  
const DailyRotateFile = require('winston-daily-rotate-file');  
const config = require('./env');  
<br/>const { combine, timestamp, json, errors, splat, printf, colorize } = winston.format;  
<br/>// ── Custom Console Format (Development-friendly) ──────────────────────────────  
const consoleFormat = printf(({ level, message, timestamp: ts, stack, ...meta }) => {  
let log = \`\${ts} \[\${level}\]: \${stack || message}\`;  
if (Object.keys(meta).length > 0) {  
log += \` \${JSON.stringify(meta)}\`;  
}  
return log;  
});  
<br/>// ── Base Format (JSON for production, structured for parsing) ─────────────────  
const baseFormat = combine(  
timestamp({ format: 'YYYY-MM-DD HH:mm:ss' }),  
errors({ stack: true }),  
splat(),  
json()  
);  
<br/>// ── Transports ────────────────────────────────────────────────────────────────  
const transports = \[\];  
<br/>// Console transport (always active, colorized in dev)  
transports.push(  
new winston.transports.Console({  
level: config.LOG_LEVEL,  
format: config.isDevelopment  
? combine(colorize({ all: true }), timestamp({ format: 'HH:mm:ss' }), consoleFormat)  
: baseFormat,  
})  
);  
<br/>// File transports (production only)  
if (config.isProduction) {  
transports.push(  
new DailyRotateFile({  
filename: 'logs/error-%DATE%.log',  
datePattern: 'YYYY-MM-DD',  
level: 'error',  
maxSize: '20m',  
maxFiles: '14d',  
format: baseFormat,  
}),  
new DailyRotateFile({  
filename: 'logs/combined-%DATE%.log',  
datePattern: 'YYYY-MM-DD',  
maxSize: '20m',  
maxFiles: '14d',  
format: baseFormat,  
})  
);  
}  
<br/>// ── Logger Instance ───────────────────────────────────────────────────────────  
const logger = winston.createLogger({  
level: config.LOG_LEVEL,  
defaultMeta: { service: 'tu-mock-test-api' },  
transports,  
// Capture uncaught exceptions  
exceptionHandlers: config.isProduction  
? \[  
new DailyRotateFile({  
filename: 'logs/exceptions-%DATE%.log',  
datePattern: 'YYYY-MM-DD',  
maxSize: '20m',  
maxFiles: '14d',  
format: baseFormat,  
}),  
\]  
: \[new winston.transports.Console()\],  
// Capture unhandled promise rejections  
rejectionHandlers: config.isProduction  
? \[  
new DailyRotateFile({  
filename: 'logs/rejections-%DATE%.log',  
datePattern: 'YYYY-MM-DD',  
maxSize: '20m',  
maxFiles: '14d',  
format: baseFormat,  
}),  
\]  
: \[new winston.transports.Console()\],  
exitOnError: false,  
});  
<br/>// ── Graceful Shutdown ─────────────────────────────────────────────────────────  
process.on('SIGINT', () => {  
logger.end(() => {  
process.exit(0);  
});  
});  
<br/>module.exports = logger;
